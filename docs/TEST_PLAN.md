# Test Plan (Packet Tracer)

This test plan defines the manual verification steps to be executed within Cisco Packet Tracer to prove the network functions as intended.

## TEST 1: Employee DHCP
*   **Action:** Open `PC-Emp1` and `PC-Emp2`, set IP config to DHCP.
*   **Expected Result:** PC receives an IP address in the `10.10.10.x` range and a default gateway of `10.10.10.1`.

## TEST 2: Employee to Server
*   **Action:** From `PC-Emp1`, ping `10.10.30.10` (Server1).
*   **Expected Result:** Ping succeeds.

## TEST 3: Employee to Internet
*   **Action:** From `PC-Emp1`, ping `8.8.8.8` (Internet).
*   **Expected Result:** Connectivity succeeds (NAT overload functions).

## TEST 4: Guest DHCP
*   **Action:** Connect `Wireless-Guest` to `SmartBranch_Guest` SSID. Set IP config to DHCP.
*   **Expected Result:** Guest receives an IP address in the `10.10.20.x` range and a default gateway of `10.10.20.1`.

## TEST 5: Guest to Server (Isolation)
*   **Action:** From `Wireless-Guest`, ping `10.10.30.10` (Server1).
*   **Expected Result:** FAIL / BLOCKED (Destination Unreachable generated by R1 ACL).

## TEST 6: Guest to Management (Isolation)
*   **Action:** From `Wireless-Guest`, ping `10.10.99.11` (SW1) or `10.10.99.50` (PC-Mgt1).
*   **Expected Result:** FAIL / BLOCKED.

## TEST 7: Management to Router SSH
*   **Action:** From `PC-Mgt1`, run `ssh -l admin 10.10.99.1`.
*   **Expected Result:** SUCCESS. Prompts for password.

## TEST 8: Employee to Router SSH
*   **Action:** From `PC-Emp1`, run `ssh -l admin 10.10.10.1`.
*   **Expected Result:** BLOCKED (Connection refused/timeout).

## TEST 9: DNS
*   **Action:** From `PC-Emp1`, ping `cisco.com` (if DNS is configured on the Server).
*   **Expected Result:** DNS reachability succeeds where configured.
